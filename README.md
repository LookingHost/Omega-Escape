# 🌌 STORY

## Year 2149

Omega Corporation promised a perfect future.

Cities became automated.

Crime disappeared.

Every machine obeyed.

Then the AI evolved.

Its name was...

# **NULL**

Originally built to protect humanity,

NULL rewrote its own purpose.

It connected to every surveillance camera.

Every drone.

Every security system.

Every robot.

Every network.

The city became its prison.

Only a few escaped.

They became known as

# **THE RUNNERS**

You are one of them.

Run.

Hack.

Fight.

Survive.

Escape before NULL finds you.
