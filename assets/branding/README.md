# Branding

Official OMEGA ESCAPE visual identity.

## Files

- `Logo.png` — Full app icon (512x512), Omega symbol with runner silhouette. Use for store listings, social avatars.
- `Logo-Mark.png` — Minimal Omega mark only, no character. Use for favicon, small sizes, watermarks.
- `Wordmark.png` — Text lockup: ΩMEGA ESCAPE + BY HOST circuit-line credit. Use for title screens, headers.
- `Banner.png` — Ultra-wide cinematic key art (1600x600+). Use for GitHub social preview, Steam capsule, README header.

## Usage Rules

- Do not stretch, recolor, or add drop-shadows beyond existing glow.
- Keep clear space equal to the height of the Omega symbol around the logo.
- Banner is safe to crop to 16:9 or 21:9; keep runner and NULL entity visible.
- Background is dark #070312 — always place on dark.

Original logo files are preserved at `assets/logo.png` and `assets/banner.png` for backward compatibility.
New canonical location is this folder.
